# 机场手记的推广关系与资料范围

本项目包含邀请链接。你通过这些链接注册并完成符合厂商规则的购买后，项目维护者可能获得佣金。佣金由厂商结算，本项目不收取你的套餐费用。

邀请链接会在入口旁明确标记，也提供不含邀请码的官网入口。是否获得优惠、价格是否相同、如何归因以及佣金如何结算，以当时厂商条款为准；没有核实的优惠不会作为购买承诺。

## 编辑原则

- 收录表示建立档案，不表示推荐购买。
- 汇总厂商说明、第三方公开评测、社区反馈和维护者材料，逐项注明来源。
- 维护者体验可选，不以逐家亲测作为收录门槛；商家或社区结论不会变成本人的实测结论。
- 不根据佣金比例给厂商排序，不编造使用体验、销量、评分或提现记录。
- 分类标签用于发现资料，不表示性能认证。`documented` 只表示已有来源资料。
- 有缺点、故障和退款反馈时同样保留来源及适用条件。
- 不把一次成功连接、测速或到账当作长期表现保证。
- 收到赞助、赠送套餐或付费合作时，需在对应记录中补充说明。

黄页中的具体资料范围以各条目的来源、日期、状态和待核验事项为准。有来源资料不等于维护者已确认当前价格、线路稳定性、退款执行或佣金提现能力。
