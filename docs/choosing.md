# 从需求开始选套餐

先在黄页找出几个候选，再阅读原始条款。这里提供比较方法，具体产品信息以各厂商档案的来源和日期为准。

## 先确定预算与付款周期

对比一次实际需要付多少钱，不要只看折算月费。

- 月付：先看一个月的总额，以及续费是否恢复原价。
- 季付或年付：同时看预付款总额、期限和每月流量；折算费用不代表支持按月付款。
- 按量：看总流量、有效期、线路倍率和流量用完后的处理方式。

例如：年付 189 元、每月 100 GB，对应一次支付 189 元，流量按月重置；不是每月只付 15.75 元，也不是整年只有 100 GB。这个例子来自本项目收录的 [边界云套餐资料](../reviews/bianjiecloud.md)，属于报价说明，不表示推荐。

## 再看自己的使用条件

| 你关注的事 | 继续核对 |
| --- | --- |
| 偶尔使用 | 套餐有效期、最低付款额、按量流量是否到期 |
| 高频使用 | 每月额度、线路倍率、限速及公平使用规则 |
| 特定国家或地区 | 购买时的节点列表、是否固定出口、变更说明 |
| 住宅 IP | 商家描述、具体 IP 属性与实际任务中的表现 |
| 新手配置 | 是否有适配设备的客户端、安装来源、使用文档 |
| 同时多设备 | 设备数、连接数、账号共享与路由器使用规则 |

“家宽”“专线”“不限量”“永久”等标签需要结合条款理解，单靠名字无法判断稳定性、隐私能力或长期运营情况。

## 如何读价格与评价

1. 官网报价：说明商家页面展示了什么，服务表现仍需另查。
2. 第三方报价：保留作者和摘录日期，原文未标价目更新时间时，不当作当前成交价。
3. 历史公告：帮助发现线路、域名与服务变化，不能直接当作今天的故障状态。
4. 使用记录：关注地区、运营商、时段、套餐和客户端版本；与你的条件差异越大，参考范围越有限。

出现矛盾时先看原文和适用条件。黄页会保留冲突线索，不把多个优惠叠加计算，也不以维护者佣金决定排序。

## 做决定前

确认结算总额、周期、配额、退款条件和客服渠道。邀请注册链接与普通官网入口会分别列出，是否使用邀请入口由你决定。
