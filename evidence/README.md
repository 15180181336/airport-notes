# 公开证据

这里存放经过人工检查、可以公开的截图或日志。黄页收录不要求逐家上传实测证据：厂商说明和第三方公开资料可以通过 `data/catalog.json` 中的来源链接引用。

按厂商 ID 创建子目录，文件名建议包含观察日期和简短说明。保留原始文件在仓库外，公开副本需移除个人信息、支付信息和订阅凭证。

为材料注明来源、观察日期和适用条件；日期未知或原图不公开时，在来源备注中说明。截图只能支持其可见内容，不自动证明当前价格、稳定性或提现能力。

不照搬第三方长文和图片，优先链接原文并用自己的文字概括。不要把厂商营销素材、社区观点或别人的测速截图标为自己的实测证据。`experiences` 可以为空，存在记录也不意味着认证。
